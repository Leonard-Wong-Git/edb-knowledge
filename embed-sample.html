將 PolicyChecker 嵌入學校網頁

本頁示範如何用一條 iframe 將 PolicyChecker 直接嵌入學校網頁、CMS 或 SharePoint。下面個 iframe 係真正 live 嘅平台 — 試吓搜尋。

實時示範

HTML 程式碼（複製貼上）

<iframe
  src="https://policychecker.wongfu.net/app.html"
  title="PolicyChecker · 政策核對"
  style="width:100%; min-height:720px; border:0;"
  loading="lazy"
  allow="clipboard-write">
</iframe>
備註： min-height 可以按學校網佈局調整。建議至少 600px 確保搜尋介面有足夠空間。

常見問題

Q：學校 IT 同事點 deploy？

  • 登入學校 CMS（例如 WordPress / Drupal / SharePoint）後台
  • 找一個 HTML widget / Custom HTML block
  • 貼入上面個程式碼
  • Save + 預覽

Q：可唔可以指定打開某個 tab？

  • 而家 iframe 預設打開「政策搜尋」tab
  • 未來會加 URL query parameter 支援（例如 ?tab=guidelines）— 提需求即加

Q：個 iframe 會跟學校網頁顏色嗎？

  • 唔會 — PolicyChecker 內部有自己嘅排版同顏色（navy + paper tone）
  • iframe 邊框已關閉、整合視覺上自然
