## 操作流程

1. **下載第一批** 8 份行政文件（PDF + 部分 HTML 轉 PDF）
2. 上傳至對話（多個一次過上傳即可）
3. 我建立 extract → 提取 Channel A 候選
4. 你在 Dashboard 審批
5. 你在本地 `python3 dev/vault/build_wiki_index.py` 重建 Channel B index

重複上述流程處理第二批課程指引。
