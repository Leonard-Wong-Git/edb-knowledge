# Infographic 生成 Prompt（輸出 PNG ・ 繁體中文 ・ 書面語）

> 貼落任何識寫 HTML + 可以截圖嘅 agent（Claude Code / Cursor / Codex 等）。
> **唔好用純圖像生成模型**（Midjourney / DALL·E 類）—— 中文密集文字會出亂碼同錯字。
> 三條 prompt 全部自足：資料已經寫死喺 prompt 入面，agent 唔使查任何嘢。
> 數字出處：`dev/PROJECT_MILESTONES_REVIEW.md`；改數字前同 `dev/SESSION_HANDOFF.md` 對返。

---

## Prompt A — 完整版（單頁縱向長圖）

```text
請幫我製作一張資訊圖（infographic），主題係一個真實軟件專案五個月嘅開發歷程回顧。

【輸出要求 — 最重要】
1. 最終交付物係一個 **PNG 圖片檔**，唔係 HTML。
2. 製作方法：先寫一個自足嘅 HTML 檔（inline CSS，**零外部資源**：唔准 CDN、唔准網上字體、唔准網上圖片），
   然後用 headless 瀏覽器截圖成 PNG。例如：
   chrome --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=2 \
          --window-size=1200,9000 --screenshot=out.png file:///絕對路徑/infographic.html
   截完之後自動裁走底部多餘嘅背景色（用 Pillow 由下而上搵最後一行非背景色像素，留 96px 邊距）。
3. HTML body 闊度固定 1200px，高度隨內容延伸；device scale factor 用 2（即 PNG 闊 2400px），確保文字銳利。
4. 字體堆疊必須包含繁體中文字體，順序：
   "PingFang TC","Heiti TC","STHeiti","Hiragino Sans CNS","Songti TC",sans-serif
5. 截圖之後請**打開 PNG 檢查一次**：有冇文字被切走、有冇方格豆腐字、有冇區塊爆版。
   如果最底一行內容貼住邊緣，加大 window-size 再截。

【語言要求】
· 全部文字用**繁體中文**。
· 用**書面語**，唔准用粵語口語（例如要寫「並不是」而非「唔係」、「因為」而非「因為……嘅」）。
· 香港用語：寫「搜尋」唔寫「搜索」、寫「片段」唔寫「块」、寫「程式」唔寫「程序」。

【專案背景】
名稱：PolicyChecker ・ 香港學校政策搜尋平台（policychecker.wongfu.net）
定位：為香港中小學及幼稚園學校管理人員提供一個有根有據、可追溯至教育局官方文件原文嘅政策查詢平台。
核心承諾：回答一個問題時，能夠指出答案出自哪一份文件、哪一頁、哪一章。
```
